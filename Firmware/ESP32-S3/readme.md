## Archivos
- `main` Esta carpeta contiene el componente principal del firmware para el detector SOLEAC basado en ESP32-S3. Aquí están el punto de entrada de la aplicación, los módulos de procesamiento y periféricos, y la configuración de compilación del componente ESP-IDF.
- `.gitignore` Ignora artefactos locales de ESP-IDF
- `CMakeLists.txt` Define el proyecto ESP-IDF SOLEAC
- `CMakeLists.txt` Documenta el entorno de compilacion del firmware
- `dependencies.lock` Fija versiones de dependencias ESP-IDF
- `sdkconfig`	Agrega configuracion ESP-IDF usada
- `sdkconfig.defaults` 	Agrega valores predeterminados de ESP32-S3
